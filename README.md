# system-lab

C++ 基础练习与模拟数据工具仓库。当前记录 2026 年 9 月 30 日的“整合模拟数据小程序”：使用 Python 生成 CSV，通过 C++ 命令行程序读取并输出最大值、最小值和平均值。

## 环境要求

- CMake 3.23 或以上。
- 支持 C++17 的 C++ 编译器。
- Python 3；数据生成只使用标准库，无需安装第三方包。
- 以下命令以 Ubuntu / Bash 为例，除特别说明外均从仓库根目录执行。

如果现有环境中的 `python` 已指向 Python 3，可以将下面的 `python3` 换成 `python`。

## 构建

```bash
cmake -S . -B build-debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build-debug --target day_260930
```

修改源码后，重新执行第二条构建命令，再运行程序。构建失败时，应先处理错误，避免误用旧的可执行文件。

## 数据格式

使用简单的单列 CSV：

```text
value
1
5
0
```

第一行约定为 `value`，之后每行一个数。当前 C++ 程序跳过首行，对数据行调用 `strtod` 转换；移除数据行末的 `\r` 后检查字段是否完整转换，因此能处理普通 LF 和 CRLF 数字记录。

练习只使用自己生成的模拟数据，不处理多列、带引号或字段内含逗号的通用 CSV。有效样例不在数据区域插入空行。

## 生成三种规模的数据

输出路径必须以小写 `.csv` 结尾，父目录必须存在。当天生成器的路径相对于启动命令所在目录解析，按下面的命令从仓库根目录运行：

```bash
mkdir -p test_file/260930
python3 Python-src/day_260930.py test_file/260930/small.csv 10
python3 Python-src/day_260930.py test_file/260930/medium.csv 100
python3 Python-src/day_260930.py test_file/260930/large.csv 1000
```

第 `i` 条数据为 `i % 10`，`i` 从 0 开始，因此这些数据是确定生成的循环序列，并非随机数据。运行命令会覆盖对应输出文件。

| 文件 | 数据记录数 | 含表头行数 | 最大值 | 最小值 | 平均值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `small.csv` | 10 | 11 | 9 | 0 | 4.5 |
| `medium.csv` | 100 | 101 | 9 | 0 | 4.5 |
| `large.csv` | 1000 | 1001 | 9 | 0 | 4.5 |

旧脚本 `Python-src/day_260928.py` 使用以 `../test_file/` 开头的路径，若使用它，应从 `Python-src` 目录运行。当天的三规模数据统一使用 `day_260930.py`，无需切换目录。

```bash
./build-debug/day_260930 test_file/260930/data.csv
```

程序先显示文件与读取的记录，再输出：


三份生成数据可以分别输入同一个程序复测：


三份文件预期均为最大值 9、最小值 0、平均值 4.5。生成了文件不等于已经实际运行过这三条分析命令。

## 当前边界与后续改进

- 数据区域的空行尚未拒绝：移除 `\r` 后，空字符串会被当作数值 0。应同时检查至少发生了一次数字转换；这与零字节空文件正确显示 `No` 是不同情况。
- 当前只跳过首行，尚未检查表头是否确实为 `value`。
- 尚未限制非有限数字和转换溢出；正常练习使用有限、小范围模拟数值。
- Python 生成器当前假定命令行参数齐全、记录数为非负整数、父目录存在。生成器扩展名错误会打印提示，但没有设置非零退出码。
- Python 函数说明中的“随机整数”与实际循环序列不一致，后续可修正文档字符串。
- C++ 使用 `std::strtod` 时，后续宜显式包含 `<cstdlib>`，避免依赖其他头文件的间接包含。

这些后续改进不增加当天的编程练习数量。当天原计划的产出是文件输入、统计输出、异常验证、样例数据与复现说明；源码审查和实际运行结果分别记录。
